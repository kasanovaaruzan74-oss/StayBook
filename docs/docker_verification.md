# Docker контейнерлерін нақты тексеру

Тексерілген күн: **2026-11-11 (UTC)**. Docker 29.9.2, Compose v2.40.3.

| Тексеру | Нақты нәтиже |
|---|---|
| `docker compose config` | Конфигурация дұрыс |
| Backend образы | `python:3.11-slim` негізінде жиналды |
| Frontend образы | `python:3.11-slim` негізінде жиналды |
| Екі сервисті бірге іске қосу | Backend және frontend — healthy |
| `GET http://localhost:8000/` | HTTP 200 |
| `GET http://localhost:8501/_stcore/health` | HTTP 200 |
| Frontend → `http://backend:8000/rooms` | Docker ішкі DNS арқылы HTTP 200, 5 нөмір |
| Бастапқы база | Төрт кестенің әрқайсысында 5 жазба |
| Контейнердегі пайдаланушы | UID 10001, `/data` жазуға қолжетімді |
| Тірі API арқылы POST/PATCH/іздеу | 201, 200 және сәйкес сүзілген нәтиже |
| Толық `docker compose down` → қайта іске қосу | Жаңа жазба және өзгертілген қонақ email-і сақталды |
| Бастапқы деректерді қайта қоспау | `seed.py --if-empty` бұрынғы деректерге тимеді |

Образдар алдымен жеке Docker build командаларымен жиналды. Содан кейін Compose-тің мына командалары орындалды:

```bash
docker compose up --no-build --detach --wait
docker compose ps
docker compose down
docker compose up --no-build --detach --wait
```

Қайта іске қосу тексеруінде `-v` қолданылмады. Сондықтан `staybook_data` named volume-дағы SQLite файлы сақталды. Қалыпты компьютерде құрастыру мен іске қосуды біріктіретін команда: `docker compose up --build`.

Cloud-та образ құрастыру кезінде ортаның CA сертификаты уақытша BuildKit secret арқылы берілді; TLS тексеруі қосулы қалды. Dockerfile ішінде бұл secret міндетті емес: қалыпты жергілікті ортада қосымша сертификат қажет болмайды.

Тексеру аяқталған соң уақытша жазбалар жойылып, өзгертілген мысал email қалпына келтірілді. Демонстрация базасында әр кестеде қайтадан 5 жазба қалды.
