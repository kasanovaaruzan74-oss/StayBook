# Зертханалық жұмыс №2

**Тақырып:** реляциялық дерекқор және SQLModel ORM модельдері.

## Мақсат

Бірінші жұмыстағы ER-сызбаны Python кластарына көшіру, кілттер мен объектілік байланыстарды баптау және SQLite базасына мысал жазбалар енгізу.

## 1. Модельдер

`app/database/models.py` файлында төрт кесте анықталады:

| Модель | Кесте | Негізгі өрістер |
|---|---|---|
| Қонақ | `guests` | `id`, `full_name`, `phone`, `email` |
| Нөмір санаты | `room_categories` | `id`, `name`, `description` |
| Қонақүй нөмірі | `rooms` | `id`, `category_id`, `room_number`, `price_per_night`, `capacity` |
| Брондау | `bookings` | `id`, `guest_id`, `room_id`, `check_in`, `check_out`, `status` |

`id` — бастапқы кілт. `category_id`, `guest_id`, `room_id` — сыртқы кілттер. Қонақтың телефоны мен email-і, санат атауы және нөмір белгісі қайталанбауы тиіс. Ақша `Decimal` негізіндегі сандық өріспен беріледі, күндер `date` түрінде сақталады.

`Relationship` арқылы бір санаттың нөмірлеріне, бір қонақтың брондауларына және бір нөмірдің брондауларына Python объектілері ретінде қатынауға болады. Бұл өрістердің өзі SQL кестесіне бөлек баған болып қосылмайды.

ИИ сұрауының үлгісі:

> ER-сызбаға сәйкес Guest, RoomCategory, Room, Booking SQLModel модельдерін жаса. Бастапқы және сыртқы кілттерді, бірегей өрістерді, бірден көпке Relationship байланыстарын көрсет. Бағаға Decimal, брондау күндеріне date қолдан. Кесте атаулары guests, room_categories, rooms, bookings болсын.

## 2. Дерекқорды қосу

`app/database/db.py` файлындағы `engine` дерекқорға қосылымдарды басқарады. Әдепкі URL:

```text
sqlite:///./database.db
```

`init_db()` функциясы `SQLModel.metadata.create_all(engine)` көмегімен жоқ кестелерді жасайды. SQLite үшін сыртқы кілттерді тексеру қосылады. `DATABASE_URL` арқылы бөлек тестілік база таңдауға болады.

Кестелер схемасын өзгерткенде `create_all()` бұрыннан бар бағандарды автоматты көшірмейді. Бұл оқу жобасында бастапқы схеманы қайта жасау үшін бөлек жаңа база қолдануға болады; құнды деректері бар базада миграция қажет.

## 3. Бастапқы деректер

Жобаның түбірінде:

```bash
python seed.py
```

Скрипт алдымен кестелерді дайындайды, содан соң әр кестеге 5 тестілік жазба енгізеді. Жазбалар жалған мысал деректер ретінде қолданылады. Бірдей бастапқы деректермен қайта орындау жазбаларды көбейтпейді. Бұрынғы деректер өңделген не жойылған базаға қайта іске қосқанда `python seed.py --if-empty` қолданыңыз: ол деректері бар базаны толықтырмайды және өзгерістерді сақтайды.

SQL командаларын көру, Linux/macOS:

```bash
SQL_ECHO=1 python seed.py
```

Windows PowerShell:

```powershell
$env:SQL_ECHO = "1"
python seed.py
Remove-Item Env:SQL_ECHO
```

Логта кестелерді тексеру/жасау және алғашқы іске қосуда деректерді енгізу сұраулары көрінеді. Кесте бұрын жасалған болса, әр іске қосуда `CREATE TABLE` қайталануы міндетті емес.

## 4. Git-те сақтау

`.gitignore` ішінде кемінде `venv/`, `.venv/`, `*.db`, `.env`, `__pycache__/` болуы керек. Код сақталады, ал база мен виртуалды орта қайта құрылады.

```bash
git add app/database/models.py app/database/db.py seed.py .gitignore
git commit -m "feat: add SQLModel ORM models and database seed script"
git push origin main
```

## Қорғауда көрсету

`python seed.py` командасын орындау, сыртқы кілттерді және `Relationship` мағынасын түсіндіру. Бір кестеге қатысты Python класын ER-сызбадағы блокпен салыстыру. Бақылау сұрақтарының жауаптары [осында](defense_questions.md#зертханалық-жұмыс-2).
