## Автоматты тексеру

```text
python -m pytest tests -q

```

API интеграциялық тесттері әр тестке бөлек уақытша SQLite базасын қолданды. Қосымша Streamlit AppTest сценарийлері динамикалық іздеу, POST формасы және сервер қолжетімсіздігін тексерді.

| Бағыт | Нәтиже |
|---|---|
| Төрт ORM кестесі, сыртқы кілттер және Relationship | Өтті |
| Seed-ті жеке командамен екі рет орындау | Әр кестеде 5 жазба; қайталанған жазба жоқ |
| Контейнердің seed --if-empty қайта іске қосылуы | Өңделген email мен жойылған брондау өзгеріссіз сақталады |
| Негізгі GET/POST TestClient тесттері | tests/test_api.py: 200 және 201 |
| Streamlit автоматты іздеу және POST формасы | Қосымша іздеу батырмасынсыз query параметрлері жіберіледі; форма тізімді жаңартады |
| GET тізім және ID бойынша іздеу | Өтті; жоқ ID — 404 |

| PATCH кезінде тек берілген өрістерді өзгерту | Өтті; қалған өрістер сақталады, айқын null — 422 |

## Браузерде тексеру

Docker контейнерлерінде жұмыс істеп тұрған FastAPI және Streamlit серверлері Chromium браузерінде ашылды. Скриншоттар нақты жұмыс істеп тұрған беттерден алынды:

- [GET /rooms: 200 жауабы](screenshots/swagger_get.png).
- [Теріс баға: POST /rooms → 422](screenshots/swagger_validation.png).
- [Нөмірлер интерфейсі](screenshots/frontend.png).
- [Автоматты іздеу нәтижесі](screenshots/frontend_search.png).

Streamlit-тің төрт бөлімі AppTest арқылы да ашылып тексерілді. Браузерде нөмірлер мен брондаулар беттері қосымша тексерілді. Интерфейстен жаңа нөмір қосу және растау белгісімен өшіру толық орындалды; кейін сол ID-ге API сұрауы 404 қайтарды. Тексеру үшін қосылған уақытша нөмір тазартылды.

## Docker тексеруі

Екі образ Python 3.11 негізінде нақты жиналды. Екі сервис те healthy, ішкі http://backend:8000 байланысы, CRUD және тұрақты volume тексерілді. Толық down/up циклінде енгізілген жазба мен өзгертілген email сақталды. Нақты нәтижелер [Docker есебінде](docker_verification.md) берілген.

## Орындалу ортасы

Python 3.12.14, FastAPI 0.162.4, SQLModel 0.0.48, Streamlit 1.67.0, pytest 9.2.0. Орнатылған пакеттердің нақты нұсқалары `requirements.lock.txt` ішінде сақталған.

Бұл нәтижелер әзірлеу ортасындағы тексеруге жатады. Студенттің жеке компьютерінде Cursor/VS Code орнатылғаны немесе қорғауды өзі өткізгені туралы мәлімдеме жасалмайды. Жеке компьютерде іске қосу қадамдары README ішінде берілген.
